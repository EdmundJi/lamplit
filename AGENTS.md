## OpenWiki

This repository has a generated `openwiki/` evidence index. It is optional just-in-time context, not required startup reading.

- Treat source code and tests as authoritative. A brief's unknowns and review items are verification gaps, not automatic requirements.
- Prefer the narrowest quiet validation that proves the changed behavior. Preserve complete failure output.

OpenWiki updates are deliberate and manual; this repository does not schedule automatic regeneration. Do not hand-edit generated OpenWiki content pages unless explicitly asked. Put durable scope and evidence rules in `openwiki/INSTRUCTIONS.md`, then use `openwiki code --update` so pages and grounded Claims remain consistent.
