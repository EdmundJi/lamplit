# 小镇产品体验完善 · M10（2026-09-07）

产品目标：现实成长留下生活痕迹，让用户容易开始行动、获得温和陪伴，并逐渐形成归属。完整方案与执行记录位于 `plan.md` 顶部。

## 本轮实现

| 模块 | 可用体验 | 数据与边界 |
| --- | --- | --- |
| 入住与回家 | 三步可跳过入住：配色、手账、小助；一条基于任务/未读状态的欢迎提示；关闭后本次进入不重复 | 不编造昨天的经历；沿用账号的新手完成记录 |
| 双路径操作 | 今天、信箱直接打开；场景物品仍走近再使用；主要导航收敛，地点入口按空间用途组织 | 复用原任务、专注、AI第一步和伙伴能力 |
| 手机窗口 | 一次一个主业务窗口，底部功能栏可点击；今天/目标/AI输入在切换时保留 | 信箱关闭/最小化卸载私密内容；专注弹窗隐藏后不抢焦点 |
| 居民日程 | 早晨、傍晚与部分晚间活动，短间隔连续外出，长间隔回家休息；当前位置和下一站可导航 | 服务端确定性日程；已冻结当天/历史不重算，兼容旧节律在下一次生成时受益 |
| 我的家 | 原木日常、草木清晨、暮色阅读三种固定配色，真实室内家具实时预览、保存/取消/恢复默认 | 配色与纪念物收纳按账号保存在当前浏览器；不宣称跨设备装修同步 |
| 纪念墙 | 查看已获得成就的名称、日期、获得缘由，可选择摆放/收纳 | 不创造奖励，室内近处卡片显示已选纪念；仍以已有成就作为来源 |
| 活动闭环 | 新请柬关联具体活动；参加意向、略过、稍后决定、前往、明确记下参加、过去七天回顾 | 意向不等于参加；参加是用户主动自报，不声称位置验证。取消/结束禁用新操作，无经验/金币 |
| 连续故事 | 小助的书架、邮递员的邮包两条分段故事；参与或旁听、暂停续读、完成回看；普通/沉浸入口均接通 | 服务端持久化版本与阶段，重试不越级；人工编写的小故事，不冒充 AI 记忆；无强制跨日等待 |
| 好友拜访 | 主人主动开放精选居家小景、最多四件真实纪念；已接受好友访问并留明信片；主人收取/删除 | 默认私密；昵称/配色/所选成就才公开。静态异步展示，不是实时进入好友的 Phaser 房间 |

## 新接口

全部要求现有登录身份；写接口遵守现有 CSRF 规则。

- `GET /api/v1/town/events`：只返回小镇当天活动，新增 `phase/response/attendedAt/serverTime`，维持世界渲染数据范围。
- `GET /api/v1/town/events/history`：此前七天；`GET /api/v1/town/events/{id}`：本人具体活动。
- `POST /api/v1/town/events/{id}/response`：`{response: UNDECIDED|GOING|SKIPPED}`。
- `POST /api/v1/town/events/{id}/memory`：进行中主动记录参加；重复调用保留首次时间。
- 收信结果新增可空 `eventPublicId`；旧请柬不猜时间/活动身份；晚间首次进入不补造已开始活动。
- `GET /api/v1/town/stories/{GUIDE|POSTMAN}`；`POST /.../advance`：`{action,expectedStage,expectedRevision}`，过期版本返回当前进度，不再推进。
- `GET /api/v1/town/visits`：允许访问的好友；`GET/PUT /.../mine`：个人分享；`GET /.../{owner}`：好友展示。
- `GET /api/v1/town/visits/received`：最近100张收到的明信片；`POST /.../{owner}/postcards`：`{body,requestKey}`，同内容失败重试复用键；`DELETE /.../postcards/{id}`：主人或作者删除。

新增迁移：V26 活动状态与请柬关联、V27 居民故事、V28 好友分享与明信片。先应用后端迁移再发布前端；本轮不部署共享开发机。

数据导出增加 `town_experience.json`，只包含本人相关的新数据。注销处理清理故事、分享与相关明信片，并移除个人活动参与记录。好友关系解除、主人关闭分享或账号非活动状态后，读取/投递会重新校验权限。

最终验证：前端726项、后端200项通过；TypeScript与生产构建通过。33条浏览器旅程分轮通过，末轮9/9；详细分轮记录见 `plan.md`。后端使用隔离 Testcontainers MySQL 实际应用迁移并检验授权、持久化、重试与注销；浏览器使用隔离业务 API 样例与真实 Phaser/素材，不能等同于共享开发机联调。
