# 傍晚，街角

> 此文记录的是早期独立视觉试作。用户澄清后，正式交付改为[现有小镇中的街角露台](街角露台.md)，本试作及其录像不作为现有系统集成的验收证据。

一个独立、可玩的 30 秒咖啡馆片段。用一个固定画面验证空间比例、动作连续性和生活痕迹，保留原有成长小镇及其后端数据。

## 打开

启动前端后访问 `/town/demo`，无需登录或后端；普通小镇工具栏也有「傍晚街角」入口。本次本地预览地址为 `http://127.0.0.1:5182/town/demo`。

```sh
cd frontend
pnpm town:assets
pnpm dev --host 127.0.0.1 --port 5182
```

场景复用仓库现有授权图集与人物。首次运行需要 `tmp/` 中的授权素材包，按项目 README 生成图集；缺少素材时页面会报告加载错误。

## 看与玩

- 自动开始：居民端着两杯咖啡出门，坐下放杯、喝一口。熟人从小巷走来，挥手后继续赶路。留下的人把第二杯挪回身边，起身走开；杯子和拉出的椅子保留。
- 背景居民持续读书翻页、浇花和歇息，浇过的土变深。
- 「暂停 / 继续」「再看一次」控制整个片段，重播会复位道具与土壤。
- 「隐藏气泡」观察动作本身是否可读；「收起界面」用于安静观看，Esc 或画面右下角按钮恢复。
- 「走进街角」显示玩家，可点击地面或使用 WASD / 方向键走动，自动寻路避开桌椅、树干等静物。「安静旁观」隐藏玩家。
- 「听听街角」自愿开启低音量合成微风、鸟鸣、杯碟与脚步声；暂停同时静音。
- 「保存画面」导出当前 Canvas 的 PNG。

这是一段编排好的视觉与行为演示，人物动作按绝对时间运行，便于重播和审查。没有调用模型或向生产社会系统写入虚构事实，也没有实现咖啡馆室内或成长业务面板。现有完整小镇仍从 `/town` 和 `/town/immersive` 使用。

## 验收

三个标准：任意截帧的构图适合分享；隐藏名字与气泡仍能看懂至少两个人的动作；看完三十秒能复述一件小事。

独立验收脚本使用真实 Phaser 和图集，不替换接口或渲染器，记录实际时间推进的截图、状态和录像：

```sh
cd frontend
TOWN_BASE_URL=http://127.0.0.1:5182 node e2e/town/acceptance/cafe-demo.mjs
```

产物位于 `test-results/cafe-demo-acceptance/`，包括每 5 秒的无气泡画面、30 秒后痕迹、暂停/重播、键盘/点击移动、手机横竖屏和独立结果。视觉判断必须读取截图和连续帧，不能只读 `snapshot`。

2026-09-06 最终验收：独立 agent 对三个标准均判定通过；第一项基于七个时点抽样，未声称逐帧审美验证。隐藏全部界面与气泡的实际片段推进超过 30 秒，八项浏览器功能检查全部通过，0 运行或 HTTP 错误。小镇 51 个测试文件、575 条测试通过，最终 TypeScript 与生产构建通过；另验证素材缺失提示与重新进入没有重复 Canvas。

## 实现边界

- `demo/cafe-stage.ts`：固定空间、局部光、静物、碰撞、椅子变化。
- `demo/cafe-life.ts`：人物朝向与动作、道具、两句短气泡、重播状态。
- `demo/cafe-demo.ts`：Phaser 生命周期、输入、导航与控制。
- `demo/cafe-sound.ts`：用户触发的音景与动作声音。
- `demo/CafeDemo.vue`：自适应外壳和公开入口。

后续将这些经过画面验证的动作接入真实日程时，保留动作开始、执行、收尾、物件状态的完整链路。此次片段不宣称其剧情由社会模拟自动生成。
