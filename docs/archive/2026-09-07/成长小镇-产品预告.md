# 成长小镇：今天，从一小步开始

成片：`artifacts/product-trailer/growth-town-product-trailer.mp4`，75 秒，1920×1080，30 fps，H.264 / AAC，约 15.4 MiB。

## 叙事与剪辑

| 时间 | 画面 | 作用 |
| --- | --- | --- |
| 0–12.5s | 咖啡细节、镜头拉开看见街区 | 从生活动作引入世界 |
| 12.5–27.5s | 学院、健身房、公园、邻里回应 | 展示可进入、可互动的日常空间 |
| 27.5–38.75s | AI 建议 → 阅读第一步 → 保存目标 → 今天开始 | 解释产品如何帮助现实成长 |
| 38.75–48.75s | 阅读、调整当天节奏 | 留出行动时间，也允许状态不好 |
| 48.75–57.5s | 宠物散步、回来记录完成 | 用生活镜头表达时间省略，再记录进展 |
| 57.5–70s | 归家迎接、纪念墙 | 让努力留下可回望的结果 |
| 70–75s | 沙发、宠物、产品名称 | 以归属感收尾 |

96 BPM 原创合成配乐以同一旋律贯穿，先铺陈、加速、短暂收束，再进入归家段落。镜头采用节拍切换、细节与全景交替、局部放大和留白字幕。完整剪辑参数见 `artifacts/product-trailer/edit-decision.json`。

## 与产品一起补齐的内容

- AI 建议可拆成可编辑的第一步，接入已有目标保存与今天任务流程；跨面板交接保留未保存输入。
- 今天面板明确开始、完成与已完成记录，保持同一任务的连续性。
- 室内收起提示、学院布景修正、坐下的朝向与短距离过渡、器械前侧到达位置。
- 家中显示真实已获得的纪念；室内氛围与宠物生活镜头延续现有小镇系统。
- 修复录制中发现的坐下后退出房间、已销毁角色与文字仍被更新的问题。

所有产品画面来自 `/town/immersive`。录制输入使用隔离的本地演示 API 和 AI 示例，片中持续标注；不代表真实在线 AI 响应，也不声称多人联机。邻里问候镜头另标注情境编排。完成任务的演示状态仅在实际点击完成之后生成，剪辑省略现实行动经过的时间。

## 复用素材

在 `frontend` 目录运行，先启动项目 Vite 服务，并设置 `TOWN_BASE_URL` 指向该服务：

```sh
node scripts/record-product-trailer.mjs
node scripts/capture-trailer-pickups.mjs
node scripts/capture-trailer-workflow.mjs
python3 scripts/trailer-score.py
python3 scripts/edit-product-trailer.py
```

录制依赖项目 Playwright Chromium；配乐脚本需要 NumPy；剪辑需要 Pillow 和 FFmpeg，当前脚本使用本机 Homebrew FFmpeg 与 macOS 中文字体路径。原始录制、时间标记及演示请求记录保存在 `artifacts/product-trailer/`。新增录制和剪辑模块均小于 1000 行。

本轮按要求未运行测试。检查范围是实际拍摄流程、导出视频参数及成片抽帧的独立创意审阅，不能替代功能回归测试。

独立审阅结论：可以交付。15 张最终解码帧中未发现阻止交付的遮字、黑屏或核心叙事断裂；同一阅读任务、面板交接和暖色归家成立。仍可继续提升的是主角阅读时书本细节的可见程度，以及广景空地与规整布局的空间层次。这是创意判断，未经过真实观众转化验证。
