# 现有小镇 · 街角露台

这次功能直接接入原有 `createTownGame`，普通小镇和沉浸小镇使用同一份设施、路径与居民数据。入口是地点栏的「街角露台」；玩家沿原街道走到咖啡馆外，咖啡馆本身仍可正常进入。

## 可以做什么

| 设施 | 使用过程 | 留下的变化 |
| --- | --- | --- |
| 咖啡桌 | 走近、端杯、饮用、放回 | 桌上留杯与热气 |
| 花槽 | 走近、倾斜水壶、浇水 | 土变湿，花朵可见 |
| 共享书架 | 取书、翻阅、借走；再次使用归还 | 书架上的书和空位变化 |
| 唱片台 | 走近、操作唱片、播放或关闭 | 音符、灯串、用户允许后的柔和旋律 |
| 原街道长椅 | 靠近休息，移动或再次点击离开 | 保持坐姿，离开恢复角色 |

设施支持先预约、走近后执行、多人占用、取消释放与完成回调。移动离开或进入室内会清理手持道具和姿态。道具状态按玩家在浏览器本地保存，进出屋或刷新后保留；这些互动不增加经验或成长指标。

## 居民与音乐

已有名册中、当前在咖啡馆或附近闲暇停留的居民可以顺路来使用设施。玩家播放唱片，还可以吸引附近两位没有高优先事项的真实居民做短暂出门插曲。居民沿实际碰撞路径走来，使用与玩家相同的设施，完成后沿路返回日程。

不新增演示居民，不改日程时钟，不以固定 30 秒脚本驱动居民。到访属于局部生活表现，不改写后端事实、知识传播或当天计划；当前时间与居民日程会影响最终画面中出现的人。

## 布景和取景

东侧街段改为咖啡馆外的步行露台，地砖沿用原有世界图块和网格。西侧路桩划出车辆止步位置，车辆不再穿过桌椅区域。咖啡馆、健身房、北侧公园入口保留在原世界中。

沉浸页新增「收起界面」，保留真实 Canvas 和输入；Esc 或「显示界面」恢复。打开人物对话或业务窗口时自动恢复界面，避免出现不可见的阻挡窗口。

## 代码组织

单文件以 1000 行以内为目标；原有大型引擎按职责拆分，入口保留公共 API。设施状态、动作与声音在 `town-facilities.ts`，露台布景在 `town-life-stage.ts`，引擎各职责在 `engine/`。

入口 `town.engine.ts` 为 87 行；目前最大职责模块 `engine/npcs.ts` 为 576 行。主要边界如下：

| 模块 | 职责 |
| --- | --- |
| `engine/runtime.ts` | 同一个可更新的模型、居民名册、预算与场景转换状态 |
| `engine/scene-core.ts` | 场景字段与有类型的方法组合 |
| `engine/lifecycle.ts` | 资源加载、创建、逐帧更新与销毁 |
| `engine/world.ts` | 街道、建筑、家具、碰撞与视觉元素 |
| `engine/facilities.ts` | 露台接线、真实居民预约到访与返回 |
| `engine/npcs.ts` | 居民日程、位置、动作与观察镜头 |
| `engine/conversations.ts` | 交谈、气泡与主动交流 |
| `engine/navigation.ts` | 玩家路径、附近交互、输入和摄影取景 |
| `engine/rooms.ts` | 进入、退出室内与失败恢复 |

公共 API 和既有纯函数导出保持兼容；异步更新通过同一个 `TownRuntime` 访问，避免拆分后捕获过期模型。587 条小镇单元测试与生产构建已通过。

## 验证与录像

独立录制脚本：`frontend/e2e/town/acceptance/town-live-record.mjs`。本次使用隔离浏览器中的本地演示数据，访问实际 `/town/immersive`，通过真实界面和鼠标操作设施。数据适配器只提供 API 输入；移动、日程推进、设施占用、动作、道具和声音均由现有小镇的生产代码执行，不访问私人账号。视频明确标注数据来源，不能据此声称验证了真实后端。

产物目录为 `test-results/town-integrated-demo-data/`。此前自动审批拒绝了复用本机测试凭据并保存登录会话，最终选择完全不读取凭据、不登录、不保存认证会话的替代方案。

```sh
cd frontend
TOWN_DEMO_DATA=1 TOWN_BASE_URL=http://127.0.0.1:5182 node e2e/town/acceptance/town-live-record.mjs
```

如后续明确授权使用真实会话，可不设置 `TOWN_DEMO_DATA=1` 并传入 `TOWN_STORAGE_STATE`，输出另存 `town-integrated-live`，与演示数据证据分开。登录会话属于敏感本地文件，不进入 Git 或录像。

本轮完整回归：587 条单元测试、21 条真实 Canvas 浏览器旅程与生产构建通过。录像使用当前小镇页面，不能以先前独立街角试作的视频替代。

独立最终验收已通过最初三个标准，视觉第一项按七个时点抽样，不声称逐帧穷尽检查。玩家在片段内实际完成咖啡、借书和浇花，居民同期使用设施并返回日程，最后约五秒保留生活痕迹。视频为 1440×900、精确 30.000 秒，H.264/AAC；导出音轨增加 14dB，游戏本身音量未改。
