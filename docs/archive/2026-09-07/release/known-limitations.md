# 已知限制

- 本地验收使用确定性的千问 mock provider。真实千问调用路径已有契约测试，但本次未向外部供应商发送请求。
- 本地开发入口为 HTTP；生产环境必须由 TLS 终止层提供 HTTPS，并启用安全 Cookie。
- Compose 是单机开发拓扑，不提供 MySQL、Redis 或对象存储高可用和跨区域容灾。
- 通知模块覆盖偏好、每日限额、去重和投递记录；实际邮件/推送供应商适配器需在部署环境接入。
- 附件流程保留扫描状态和关联约束；生产环境仍需接入实际恶意文件扫描服务。
- Flyway 11.7.2 会对 MySQL 8.4 输出“较新版本未验证”的兼容性提示，当前迁移和全部集成测试均已通过。
