# 安全检查清单

- [x] 访问令牌和刷新令牌仅使用 `HttpOnly` Cookie，前端不持久化令牌。
- [x] 非 GET API 使用双提交 CSRF 校验；客户端请求携带 `credentials: include`。
- [x] 密码使用 Argon2id；密码重置和 MFA 密钥有独立保护与失效流程。
- [x] 刷新令牌轮换并检测重放；注销、改密和注销账户会撤销会话。
- [x] 用户资源查询包含所有权边界，越权资源按 404 处理。
- [x] 后台安全详情按角色脱敏；敏感发布要求近期 MFA 和独立复核人；审计记录不可变。
- [x] AI 输入和输出均经过 L0-L3 安全分类；L3 使用固定危机响应并禁止普通 delta。
- [x] AI 内容作为纯文本渲染，无 `v-html`。
- [x] 数据导出限频、24 小时过期，下载对象使用 MinIO/S3 AES256 服务端加密。
- [x] Nginx 配置 CSP、安全响应头、请求 ID、API 禁止缓存和 SSE 禁止缓冲。
- [x] 本地密钥文件、构建产物、浏览器产物和日志均被 Git 忽略。
- [x] 最终扫描不允许追踪文件包含供应商密钥、Cookie、访问令牌或测试密码日志。

生产发布前仍需在部署平台注入独立随机密钥、启用 TLS，并完成真实供应商最小权限密钥轮换。
