# 极简清单模式

已实现第一版：只需任务名称即可保存，打开今日页即可执行；两种模式共用后端任务与事件记录。

## 入口

- 桌面侧栏底部「切换极简清单」，或「设置 → 使用模式」。
- 极简模式页头「切换成长模式」可返回原界面。
- 模式偏好按账号保存在当前浏览器；切换不迁移、不复制任务。

## 行为

- 「今天」显示今天及更早的待执行事项、今天记录完成的事项；「全部」同时显示未来待办及历史完成记录。
- 输入任务名称并回车添加，不要求目标、角色、属性、时长或状态检查。输入失败保留草稿，同一内容的失败重试使用同一幂等键。
- 单击圆圈完成，无需先开始。已完成默认折叠；最近一次完成、删除或延期可撤销。
- 点击名称行内编辑。周期任务名称属于任务定义，会影响该任务的其他执行实例；编辑时有说明。
- 更多菜单提供上移、下移、移到明天、删除本次。桌面支持拖动；手机与键盘用户使用上移、下移。排序只保存在当前浏览器，任务内容在服务端持久化。
- 删除只取消本次执行，不会删除周期定义或历史记录。
- 新建的独立任务没有自动过期时间，跨天继续保留；旧的成长任务仍遵循原有周期和过期规则。
- 不显示成长导航、AI 快捷入口、桌宠、未读横条、欢迎教程或任务奖励反馈。
- 全部任务取消每日 4 项完成限制，原有经验奖励上限仍保留。独立清单任务不分配成长维度，不产生经验或金币。

## 数据与上线

- 新增 `POST /api/v1/tasks/quick`，请求 `{ title, localDate? }`，必须提供 `Idempotency-Key`。
- 沿用 `user_task`、`task_schedule`、任务事件与撤销接口；独立任务的 `weekly_plan_id` 为 NULL。
- 后端新增 Flyway `V25__standalone_tasks.sql`。部署此版本时先启动更新后的后端、确认迁移成功，再发布前端。
- 本次仅实现和本地验证，没有发布共享服务器。
- 第一版不包含独立任务的重复规则编辑、跨设备偏好同步、离线写入和多清单分类。
