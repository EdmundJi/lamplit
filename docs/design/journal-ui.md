# 手账界面规则

- 纸白 `#faf9f6`、墨黑 `#22221f`，朱红 `#bd422e` 仅用于日期、主要动作、当前导航和完成痕迹。正文辅色 `#686761`，分隔线 `#d8d5cd`。
- 刊头、开篇用系统宋体；事项用无衬线；日期数字用 Georgia，时间和小标签用等宽字体。不依赖外部字体请求。
- 一级标题 30–46px、开篇 23–32px、事项 17–19px。辅助元信息 11–12px，插图编号可用 9–10px。8px 为基础间距，内容组之间用 24–36px。
- 用 2px 墨线标出清单起点、1px 细线分隔事项。清单不使用独立卡片、投影或圆角容器。
- 新事项按 Enter 保存，中文输入法确认候选时不提交；保存中禁用重复提交，失败保留输入。编辑使用可换行文本区，Enter 保存、Esc 取消，完成后焦点回到下一条可操作事项。
- 完成痕迹为朱红勾和细划线；保存回执约 4.5 秒后退场，撤销入口保留。不播放庆祝动画。
- 小镇插图使用有侧面明暗的房屋、地台厚度和接地阴影。它是静态入口插图，不冒充实时镇况；小镇自己的渲染、HUD 与沉浸体验继续独立。
- 历史页读取所选日期，新增事项为该日的单次安排；沿用后端规则，需要关联覆盖该日期的进行中目标。编辑标题会更新原任务，也影响同任务的其他日期。
- 手账纸色限定在 journal-shell，保持纸面主题；小镇与独立沉浸页继续使用原主题。弹窗单独声明纸面色，避免 Teleport 丢失继承。
- 验证：单元测试覆盖保存失败、补记、额度和撤销；浏览器夹具覆盖桌面与手机的录入、长标题、编辑、勾选、焦点返回、空白页和 320/760/1024px 溢出。接口使用现有服务契约，浏览器测试不写入真实账户。
