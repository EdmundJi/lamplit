# 03 · 以后想试试

这里随手保留方向，不是排期。先把一条小街做得值得陪伴。

- **更熟悉的小人：** 记住用户主动设置的安静偏好和作息，同时保留自己的空闲生活。
- **更长的关系和故事：** 熟悉的居民因过去的经历改变选择，承诺、误会和活动有持续的后续。
- **季节与更多地点：** 延续论文的空间思路，先考虑活动、路线、相遇和声场，再扩图。一个有用的新地方比大片空地图更有意思。
- **自己的家与积累：** 选择喜欢的陈设，留下真实努力和共同经历的纪念，不强迫打卡或维护。
- **朋友的小人：** 先想异步来访或一间共享自习室，再考虑整座多人小镇。分享什么、离线时能代表用户做什么，需要一起讨论。
- **同一张地图上的所有人：** 一个用户一个小人，居民的公共生活只算一次。日活还只有几个人时省不到什么，等真有几十个人愿意天天来，再看是不是共享"居民的公共生活"、把"你和居民的关系"留在各人自己身上。要先想清楚：别人的小人看不看得见、有没有跨用户的文字、以及一个人的输入会不会顺着居民的嘴传到另一个人那里。
- **桌宠变成小人养的宠物：** 现在的 Rive 桌宠和小镇里的小人是两个"陪着你的角色"，各有各的美术和数据。让宠物归小人养，桌上那只和街上那个就是同一段生活。工作量不小，想清楚再动。
- **更丰富的离线生活：** 在线生活稳定后，再看长期补算的故事价值和模型成本。

还有几个想边做边感受的问题：小人多自主才舒服？小镇多热闹才合适？用户会想认识居民，还是更喜欢安静的声景？直接控制小人是否值得保留为可选玩法？

这些交给实际体验、开会和 PR 慢慢决定，不急着把每个想法都写成需求。
