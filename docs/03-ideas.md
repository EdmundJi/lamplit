# 03 · 以后想试试

这里随手保留方向，不是排期。先把一条小街做得值得陪伴。

上一版这一页列了九件"01 写过但代码里还没有的东西"。到今天为止，其中大部分已经做完，
所以这一页重写过：做完的搬去 [05](05-notes.md) 记数字，剩下的和新冒出来的留在这里。

## 眼下最想补的

**"办活动"和"包场"。** 现在站在咖啡馆门口，模型能想到的是喝一杯、找个位置读书、约人拼桌。
想不到的是"今晚在这儿办个读书会"——因为没有这个动作，也没有跟老板协商场地的路径。
现有的 `workArrangements` 只覆盖吧台的帮工与接手，不覆盖场地。
先看居民会不会自己往"想聚一聚"的方向走，走了再做，不要先把系统建好等着没人用。

**信念要能改回习惯。** 规则侧已经通了：一条 `belief` 的 supersedesKey 命中
`habit:<居民>:<习惯>` 时，会按 importance 拉长那条习惯的冷却。但**模型不知道这个约定**，
所以它永远不会自己产生这样一条信念。教它需要改反思的提示词。
这是"下意识 → 事后解释 → 记忆 → 信念 → 改变下一次下意识"这个环唯一缺的一段；
少了它，解释就只是一个每次调用都要付钱的旁白器。

**相遇的重问应该按变化触发，不按时间。** 现在拒绝之后隔三十分钟会重新问一次同一对人。
三十分钟是拍出来的社交时长，不该由我们定。真实的人不是每隔 N 分钟重新决定一次，
**是情况变了才重新注意到**——他合上书站起来了，他从街上走进来了。
论文里也是对 observation 做反应，场景没变就不产生新的 observation。
改成每对人记一个"上次看到他时的样子"指纹，指纹变了才重问，那个三十分钟就可以删掉。

**有些人一天做不出三件事。** 事后解释要攒够三条无意识行为才会被问。
实测一天下来，六个人里有三个的微习惯一次都没触发过——知夏的"刚做完就想藏起来"
要她自己的作品五分钟内完成，青叔和阿满的都要求特定的人恰好在场。
这几个门开得太窄。要么放宽窗口，要么降低攒够的条数，但别为了凑数把习惯变成定时器。

**项目做不完，所以没人因为做成一件事而改变。** 人格漂移里"项目完成"和"一起庆祝"
两个驱动一天触发 0 次——不是没接线（有测试逼一个项目真做到 100%，会触发），
是那一天没有任何项目攒够贡献者。一个项目要多人参与才能到 100%，而现在很少有人
去参与别人的事。这条要和上面"办活动"一起看：都是"共同做一件事"这条线太细。

## 再往后

- **更熟悉的小人：** 记住用户主动设置的安静偏好和作息，同时保留自己的空闲生活。
- **季节与更多地点：** 延续论文的空间思路，先考虑活动、路线、相遇和声场，再扩图。一个有用的新地方比大片空地图更有意思。花园现在是全镇唯一没有人的习惯会去的公共场所，那里缺的不是面积是事情。
- **自己的家与积累：** 选择喜欢的陈设，留下真实努力和共同经历的纪念，不强迫打卡或维护。
- **朋友的小人：** 先想异步来访或一间共享自习室，再考虑整座多人小镇。分享什么、离线时能代表用户做什么，需要一起讨论。
- **同一张地图上的所有人：** 一个用户一个小人，居民的公共生活只算一次。日活还只有几个人时省不到什么，等真有几十个人愿意天天来，再看是不是共享"居民的公共生活"、把"你和居民的关系"留在各人自己身上。要先想清楚：别人的小人看不看得见、有没有跨用户的文字、以及一个人的输入会不会顺着居民的嘴传到另一个人那里。
- **桌宠变成小人养的宠物：** 现在的 Rive 桌宠和小镇里的小人是两个"陪着你的角色"，各有各的美术和数据。让宠物归小人养，桌上那只和街上那个就是同一段生活。工作量不小，想清楚再动。
- **更丰富的离线生活：** 在线生活稳定后，再看长期补算的故事价值和模型成本。

还有几个想边做边感受的问题：小人多自主才舒服？小镇多热闹才合适？用户会想认识居民，还是更喜欢安静的声景？直接控制小人是否值得保留为可选玩法？

这些交给实际体验、开会和 PR 慢慢决定，不急着把每个想法都写成需求。
