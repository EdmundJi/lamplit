# 每周章程

本目录按自然周记录项目进展，时区统一使用 `Asia/Shanghai`，每周从周一开始、周日结束。

## 文件命名

- 文件名：`YYYY-MM-DD_to_YYYY-MM-DD.md`
- 已结束的自然周标记为“已归档”
- 当前自然周标记为“进行中”，在本周内持续更新

## 记录规则

每份周章程至少包含：

1. 本周主题和计划目标。
2. 已完成事项及可核对的提交、测试或文档证据。
3. 尚未完成、受限或需要延续的事项。
4. 关键决定、风险和下一步。

完成状态以代码、测试、发布验证和线上结果为准，不直接沿用未及时更新的旧计划复选框。
