# 成长小镇 · 30 秒生活片段

本轮先提交咖啡与人物互动代码，再重做展示视频。按用户要求，不继续运行测试；只进行实际录制、分镜和成片观感审阅。

[观看新版视频](../artifacts/town-film-v2/growth-town-demo-v2.mp4)

## 表达重点

新版讲“喝完一杯，遇见熟人，街角继续”，用一个小过程表达三件可见的事：角色自然接触物品、人与人会先后回应、动作结束后世界仍保留痕迹。完整保留原速拿杯与放杯，不再把30秒变成连续点击设施的清单。

| 时间 | 镜头与内容 |
| --- | --- |
| 0–7.3s | 中景缓慢推进，保留原咖啡馆、居民劳作、暖灯与唱片；玩家实际走到桌边 |
| 7.3–14.5s | 咖啡近景，展示近身接触、原人物举杯、短暂停顿与放回 |
| 14.5–23s | 玩家沿路走到邻居旁，并排面向；轻示意、第一句、回应、告别 |
| 24–30s | 镜头退回生活区域，玩家离开，杯子和唱片仍在；克制的结束字幕 |

第一遍采用上下站位，人物气泡不易对应说话者；第二遍改用正常步行到侧方接近点，实际间距约43px，保留了两次示意之间的停顿。

## 观感判断

新版比逐设施操作更像经过导演的产品预告：拿放动作可读、回应关系清楚，首尾字幕和生活场景有统一气质。它可以展示当前交互品质与生活感；仍不能把这一段当作全部 AI 能力或商业级美术完成度的证明。

当前主要限制是夜色偏灰、铺地与空间布置较规整、空地偏多。下一轮美术投入应优先提升局部明暗和有使用痕迹的空间细节，而不是继续增加按钮与设施。

## 录制来源

- 使用现有 `/town/immersive` 引擎与明确标注的本地演示数据，不登录私人账号。
- 相机、字幕、镜头站位经过安排；问候镜头调用了一次生产问候事件，画面明确标注“受控事件触发”。没有改演员坐标、原动画帧或模拟时钟，玩家通过鼠标正常走位和使用设施。
- 录制快照以 `3a893f1` 为基底，应用 `4289ff0` 的单文件隔离补丁，避开同时写入的其他场景功能。当前主分支保留了随后合入的完整环境控制。
- 导出为1920×1080、30fps、30秒，包含实际唱片音轨并提高14dB增益；后期仅叠加标题、来源标注及转码，没有替换游戏美术或加速动作。
- 当前视频展示的是场景与交互，没有演示真实后端模型生成或限知传播闭环。

录制脚本：`frontend/scripts/record-town-film.mjs`。在固定快照服务器运行时，从 frontend 目录执行：

```sh
TOWN_BASE_URL=http://127.0.0.1:5184 node scripts/record-town-film.mjs
```

输出在 `artifacts/town-film-v2/`，包含原始 WebM、分镜截图、最终 MP4 与 `direction.json`。这些大文件按仓库规则忽略；脚本和说明进入 Git。
