The bundled 45-second loop uses seconds 750–800 of the 20-minute source. It has a
90 Hz high-pass filter, a 4.2 kHz low-pass filter, a -12 dB peak limiter, and a
five-second tail-to-head crossfade. It is encoded as stereo Ogg Opus at a target of 48 kbit/s. These changes
reduce low rumble, soften intelligible speech and sharp tableware transients, keep the
download small, and make the loop boundary unobtrusive.
