# 领域概念

- [AI 辅导、建议与流式响应](ai-coaching.md) - 说明已认证 AI 辅导会话的安全处理、模型适配、目标草案和任务建议机制。涵盖 SSE 事件语义、持久化与保留，以及将建议幂等采纳到规划中的流程。
- [身份验证与所有权](authentication-and-ownership.md) - 说明注册、同意、基于 Cookie 的 JWT 会话、CSRF、防护性 MFA，以及每一项用户范围 API 操作必须遵守的所有权规则。
- [多 Agent 小镇：边界与专题入口](companion-town.md) - 说明 Companion Town 的服务端权威边界、HTTP 与前端投影入口，以及规则、模型提案、事实、记忆和信念不可混淆的约束。并导航到 harness、尝试循环、调度、状态、记忆、种子与实验等专题。
- [从事件到感知、记忆与信念](events-perception-memory-and-belief.md) - 说明小镇如何把可验证的世界变化、当面言说和个人观察分层，并将每位居民自己的记忆转化为可检索的反思与可修订信念。覆盖可见性、证据校验、记忆容量、supersession 以及规则反射和事后解释的边界。
- [成长规划、任务与进度](growth-planning-and-execution.md) - 说明经认证的成长规划与执行模型如何将目标转化为周计划、任务、日程实例、事件、经验、角色进度及伙伴金币。涵盖重复规则、幂等性、撤销、过期和保障这些结果的运行约束。
- [隐私与保留](privacy-and-retention.md) - 说明 Better Self 的隐私与数据保留机制，包括数据导出、账户与 AI 数据删除、附件处理以及定时保留任务。涵盖所有权隔离、生命周期状态和跨存储清理边界。
- [Resident Context、限知与 Prompt 输入契约](resident-context-and-bounded-knowledge.md) - 定义 ResidentMind.Context 如何从单个居民可见的世界状态和个人记忆构造，并说明模型输入、提示文字、规则校验之间不同的知识与安全边界。
- [场景种子、居民初始基因与 Warm Start](scenario-seeds-and-resident-genesis.md) - 说明 ResidentSeed、ResidentPersonas、ResidentDuties 与 TownPlaces 如何组装 25 名 NPC 的可复现实验开局，并划分手工初始世界、私有种子记忆和确定性 warm start 的边界。
- [社交与奖励系统](social-and-reward-systems.md) - 本页说明好友、消息、每日状态、成就、称号、角色进度和伙伴奖励如何以认证账户为边界，并与任务执行相连。涵盖授权规则、持久化状态、奖励与消息生命周期，以及修改时必须保持的约束。
